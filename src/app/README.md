# Orden de las páginas

Cada pestaña del menú tiene su propio archivo editable:

1. Inicio: `page.tsx`
2. Nosotros: `nosotros/page.tsx`
3. DJI Enterprise: `enterprise/page.tsx`
4. DJI Agriculture: `agriculture/page.tsx`
5. DJI Academy: `academy/page.tsx`
6. Servicios: `servicios/page.tsx`
7. Contacto: `contacto/page.tsx`

La barra de navegación se edita en `../components/Navbar.tsx`.
